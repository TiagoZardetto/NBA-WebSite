# 🏀 NBA WebSite

Landing page page responsiva sobre a história da NBA, seus principais jogadores e momentos marcantes. 
Desenvolvida para praticar **React, Tailwind CSS, desenvolvimento de interfaces responsivas** e **Testes funcionais**


<img width="513" height="256" alt="gif" src="https://github.com/user-attachments/assets/cd5e4738-c254-4d60-bba5-2af30caf1e34" />

## 🎯 Sobre o projeto

O projeto apresenta diferentes conteúdos relacionados à NBA, utilizando componentes reutilizáveis, layouts responsivos e elementos interativos.

## 🛠️ Tecnologias

* React
* JavaScript
* Tailwind CSS
* Vite

## ✨ Funcionalidades

* Layout responsivo
* Navegação entre seções
* Componentização com React
* Cards e elementos interativos
* Galeria de imagens
* Interface adaptada para diferentes tamanhos de tela
